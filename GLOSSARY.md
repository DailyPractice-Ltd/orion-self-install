# Orion

Orion is a personal sales harness installed for one business. These terms distinguish its shared capabilities from the business's own procedures.

## Language

**Harness**:
One business's installed Orion, including its identity, knowledge base, operating state, permissions, and pairing.

**Orion plugin**:
The collection of Orion's shipped skills, distributed as one versioned product for use within an installed harness.

**Harness catalog**:
The plugin listing belonging to one harness, with a stable identity that distinguishes it from other harnesses' listings.

**Shipped skill**:
A reusable procedure included in an Orion release and maintained as part of that release.

**Legacy harness**:
A harness from before 2.0, where the business's folder is itself a copy of the release.

**Deployed harness**:
A harness from 2.0 onward, which lives in a folder separate from the release and is set up for one chosen AI tool.

**Migration to v2**:
A fresh 2.0 install into a sibling folder, followed by carrying the client's own work over from the legacy harness. A legacy harness starts it with "update my harness". It finishes in a fresh session in the new folder, with "finish the migration".
_Avoid_: harness move, bridge release (there is no 1.6)

**Client-owned skill**:
A procedure the client creates or adds to their harness, managed separately from Orion's shipped plugin.

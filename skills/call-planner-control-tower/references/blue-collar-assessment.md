# Column G: blue-collar assessment

Use this format for every active Call Queue row:

`Total employees: 51–200 (LinkedIn company-size band). Blue-collar: likely fit — construction crews; count unverified.`

- Include the sourced total employee number or published range, a readable source name, and the assessment in the cell itself. A source hidden only in a note is insufficient.
- Hyperlink the **entire assessment text** to the precise supporting source, normally with `HYPERLINK(source_url, assessment_text)`. Read back both displayed text and hyperlink.
- Preserve ranges, dates and scope: group totals are not subsidiary totals; placed workers, contractors, users and LinkedIn member counts are not interchangeable with employees. Label estimates, conflicting counts and historical figures; never manufacture an exact total.
- If no defensible count is available after checking current CRM and company sources, write `Total employees: unverified`, name and link the evidence record reviewed, and flag the gap in the report. Do not substitute zero or an unrelated company's count.
- Put source date, access date, secondary evidence and limitations in the cell note; label inferred worker mix separately from a confirmed blue-collar count.
- Preserve the full-cell link during additions and rollover. Keep displaced call ask in H and supporting evidence in P, and preserve unrelated values, checkboxes, callbacks and layout. Verify every active G cell plus a native rendered sample before reporting completion.

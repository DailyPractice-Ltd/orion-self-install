# Prospecting

Read the ICP, offer, and tone in Orion's knowledge base. Use the CRM, user-owned lists, and permitted directories and registries. Confirm the target and source if the knowledge base and request leave them ambiguous. Use the requested batch size, or aim for about twenty candidates.

1. Check each candidate against the ICP and CRM history. Give each a one-line reason to pursue, linked to checkable evidence. Mark uncertain fits and disqualifications with reasons. Use verified contact details and respect source access restrictions.
2. Show the evidence and exclusions. For prospects the user selects, use the drafting steps in the `prospect-research-outreach` skill to prepare a specific first touch in their voice. Keep drafts for review only.
3. Count a touch only from logged outreach, a conversation from a verified two-way exchange, and a meeting from the calendar. Make those definitions available to Friday Report.

Verify the first run against real market data. Each candidate needs an evidenced reason and only selected candidates should have drafts.

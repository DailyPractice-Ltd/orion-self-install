# This folder is your team's memory

Plain markdown, yours, on your machine. Your agents read it before work and write to
it after work; a nightly dream agent tidies it while you sleep. Open this folder in
Obsidian if you want to *see* what your team knows — any folder is a vault.

The map lives in `INDEX.md`. Team truths in `shared/` (proposals land in
`shared/inbox.md`), role knowledge in `roles/`, each agent's own log and lessons in
`agents/<name>/`.

Two rules worth knowing: credentials never go in here (the tools refuse them, the
dream checks nightly), and "update my harness" can never touch your memories — only
this README and the tooling around the folder belong to Daily Practice.

The full promise, in plain words: `docs/memory.md`.
